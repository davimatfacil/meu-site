Regressão de Inclinações Paralelas

Predição de Pressão Arterial por Idade e Gênero

Davi Rocha

Este projeto utiliza dados fictícios criados exclusivamente para fins educacionais e demonstração de técnicas estatísticas. As conclusões NÃO devem ser aplicadas em contextos clínicos reais sem validação adequada em dados autênticos.

1 Introdução

1.1 Contexto Clínico

A monitorização da pressão arterial sistólica (PAS) é um dos pilares da medicina preventiva. A capacidade de prever trajetórias de PAS permite a identificação precoce de indivíduos em risco de desenvolver hipertensão, definida clinicamente por valores persistentes acima de 140/90 mmHg.

O envelhecimento está associado ao aumento da rigidez arterial, o que eleva a PAS de forma progressiva. Além disso, variáveis demográficas como o gênero desempenham um papel crucial devido a diferenças hormonais e fisiológicas, exigindo modelos que considerem ambos os fatores simultaneamente para uma triagem eficaz.

1.2 Objetivos

Este projeto visa:

  1. Modelar a relação linear entre idade e pressão arterial sistólica
  2. Comparar o impacto do gênero na linha de base da pressão arterial (intercepto)
  3. Fornecer uma ferramenta de predição baseada em regressão de inclinações paralelas (parallel slopes)
  4. Avaliar a performance preditiva utilizando métricas robustas

DicaExpandir: Discussão Crítica sobre R²

3.4.1 Por que o R² do modelo de gênero é enganoso?

O modelo de gênero apresenta R² = 0.992, mas isso é enganoso devido ao uso de + 0 (sem intercepto). A métrica confiável para comparação é o RSE (sigma):

  • Idade sozinha: erro de ±4.9 mmHg (BOM)
  • Gênero sozinho: erro de ±12.4 mmHg (RUIM - 2.5x pior!)
  • Ambos: erro de ±1.2 mmHg (EXCELENTE - 4x melhor!)

NotaInterpretação dos Resíduos

O gráfico de resíduos sugere que o modelo linear captura a maior parte da variabilidade, embora apresente nuances estruturais importantes:

  1. Tendência residual não-linear: A linha de suavização (LOESS, em azul) apresenta uma leve curvatura em forma de “U”, indicando que o modelo linear pode estar subestimando valores nas extremidades (idades mais jovens e mais avançadas) e superestimando no centro. Isso sugere uma leve não-linearidade não capturada, possivelmente remediável com um termo quadrático (\(\text{idade}^2\)) ou de interação (\(\text{idade} \times \text{gênero}\)).

  2. Homocedasticidade satisfatória: A dispersão vertical dos resíduos mantém-se razoavelmente constante ao longo do eixo dos valores ajustados. Não há um padrão de “funil” evidente, o que valida a suposição de variância homogênea para fins práticos.

  3. Magnitude clinicamente aceitável: Apesar do desvio estrutural mencionado no item 1, a magnitude dos erros permanece clinicamente baixa. Com resíduos contidos em ±3 mmHg e um erro padrão residual (RSE) de 1.25 mmHg (< 2% da média de ~132 mmHg), o modelo possui alta precisão preditiva adequada para triagem clínica.

  4. Pontos de atenção: Observam-se dois casos com resíduos mais elevados (> 2 e < -2 mmHg). Embora não invalidem o modelo, esses casos representam potenciais pontos de influência ou variações biológicas atípicas que merecem investigação adicional em estudos futuros.

Conclusão: O modelo de inclinações paralelas é funcionalmente adequado e robusto para uso em triagem clínica, embora a relação exata entre idade e pressão arterial possa apresentar uma complexidade adicional (aceleração não-linear com a idade) que uma função linear simples não descreve integralmente. Para aplicações de alta precisão, modelos não-lineares (ex: splines ou polinômios) poderiam capturar melhor essa curvatura.

6 Conclusões

6.1 Principais Achados

  1. Idade como preditor dominante: A cada ano de vida, a PAS aumenta aproximadamente 0.83 mmHg, refletindo o processo natural de envelhecimento vascular e aumento da rigidez arterial.

  2. Efeito do gênero como deslocador: Homens apresentam pressão arterial cerca de 10 mmHg superior às mulheres na mesma faixa etária, mesmo com taxas de envelhecimento similares (inclinações paralelas). Isso pode estar relacionado a diferenças hormonais, composição corporal e fatores fisiológicos.

  3. Excelente acurácia preditiva: O modelo combinado (idade + gênero) apresenta erro médio de apenas ±1.25 mmHg, adequado para aplicações de triagem clínica em larga escala.

  4. Melhoria substancial: Incluir gênero no modelo reduz o erro em 74.5% comparado ao uso isolado de idade, demonstrando a importância de considerar características demográficas na predição.

6.2 Aplicações Práticas

O modelo desenvolvido pode ser utilizado para:

  • Identificação precoce: Detectar pacientes em risco de desenvolver hipertensão antes que sintomas apareçam
  • Estratificação de risco: Priorizar grupos que necessitam rastreamento mais frequente
  • Educação de pacientes: Demonstrar trajetórias esperadas de PAS ao longo da vida
  • Alocação de recursos: Auxiliar na distribuição eficiente de recursos de saúde pública

6.3 Limitações Importantes

AvisoLimitações Críticas

1. Dados Simulados: Este projeto utiliza dados fictícios criados para fins exclusivamente educacionais. As relações lineares perfeitas observadas não refletem a complexidade biológica presente em dados reais.

2. Tamanho Amostral Reduzido: Apenas 30 pacientes fictícios foram incluídos, quantidade insuficiente para generalização populacional.

3. Variáveis Omitidas: Fatores críticos foram excluídos:

  • Índice de Massa Corporal (IMC)
  • Histórico familiar de hipertensão
  • Uso de medicamentos anti-hipertensivos
  • Comorbidades (diabetes, doença renal, etc.)
  • Hábitos de vida (dieta, exercício, tabagismo)
  • Fatores socioeconômicos
  • Etnia e ancestralidade

4. Linearidade Simplificada: A relação real entre idade e PAS pode ser não-linear, especialmente em idades avançadas.

5. Ausência de Validação Externa: O modelo não foi testado em amostra independente.

6.4 Abordagens Alternativas

Este projeto utilizou regressão de inclinações paralelas, mas existem outras técnicas válidas:

  • Regressão com interação: Permitir que a taxa de envelhecimento (slope) difira entre gêneros
  • Modelos não-lineares: Usar polinômios, splines ou GAM para capturar acelerações
  • Regressão quantílica: Modelar diferentes percentis (não apenas a média)
  • Modelos mistos hierárquicos: Incorporar estruturas de agrupamento
  • Machine Learning: Gradient Boosting, Random Forests para relações complexas

A escolha depende de: Questão clínica específica, dados disponíveis, tamanho amostral, requisitos de interpretabilidade.

# Introdução {#sec-intro}

## Contexto Clínico

A monitorização da pressão arterial sistólica (PAS) é um dos pilares da medicina preventiva. A capacidade de prever trajetórias de PAS permite a identificação precoce de indivíduos em risco de desenvolver hipertensão, definida clinicamente por valores persistentes acima de 140/90 mmHg.

O envelhecimento está associado ao aumento da rigidez arterial, o que eleva a PAS de forma progressiva. Além disso, variáveis demográficas como o gênero desempenham um papel crucial devido a diferenças hormonais e fisiológicas, exigindo modelos que considerem ambos os fatores simultaneamente para uma triagem eficaz.

## Objetivos

Este projeto visa:

1. Modelar a relação linear entre idade e pressão arterial sistólica
2. Comparar o impacto do gênero na linha de base da pressão arterial (intercepto)
3. Fornecer uma ferramenta de predição baseada em **regressão de inclinações paralelas** (*parallel slopes*)
4. Avaliar a performance preditiva utilizando métricas robustas

## Expandir: Discussão Crítica sobre R²

### Por que o R² do modelo de gênero é enganoso?

O modelo de gênero apresenta R² = 0.992, mas isso é **enganoso** devido ao uso de `+ 0` (sem intercepto). A métrica confiável para comparação é o **RSE (sigma)**:

- **Idade sozinha:** erro de ±4.9 mmHg (BOM)
- **Gênero sozinho:** erro de ±12.4 mmHg (RUIM - 2.5x pior!)
- **Ambos:** erro de ±1.2 mmHg (EXCELENTE - 4x melhor!)

### Verificação

```{r r2-check}
# Modelo de gênero COM intercepto
mdl_gender_int <- lm(systolic_bp ~ gender, data = blood_pressure)

cat("R² sem intercepto (+0):", glance(mdl_gender)$r.squared, "\n")
cat("R² com intercepto:     ", glance(mdl_gender_int)$r.squared, "\n")
cat("\nRSE sem intercepto (+0):", glance(mdl_gender)$sigma, "\n")
cat("RSE com intercepto:     ", glance(mdl_gender_int)$sigma, "\n")
```

**Revelação:** R² despenca de 99.2% → 8.4% quando adiciona intercepto, mas o RSE permanece idêntico (12.42). Isso prova que o R² alto era **ilusão** causada pelo `+ 0`.
:::

### Melhoria Quantitativa

```{r improvement}
reducao_erro <- (glance(mdl_age)$sigma - glance(mdl_both)$sigma) /

cat("Redução de erro ao adicionar gênero:", round(reducao_erro, 1), "%\n")
```

## Interpretação dos Resíduos

O gráfico de resíduos sugere que o modelo linear captura a maior parte da variabilidade, embora apresente nuances estruturais importantes:

1. **Tendência residual não-linear:** A linha de suavização (LOESS, em azul) apresenta uma leve curvatura em forma de "U", indicando que o modelo linear pode estar subestimando valores nas extremidades (idades mais jovens e mais avançadas) e superestimando no centro. Isso sugere uma leve não-linearidade não capturada, possivelmente remediável com um termo quadrático ($\text{idade}^2$) ou de interação ($\text{idade} \times \text{gênero}$).

2. **Homocedasticidade satisfatória:** A dispersão vertical dos resíduos mantém-se razoavelmente constante ao longo do eixo dos valores ajustados. Não há um padrão de "funil" evidente, o que valida a suposição de variância homogênea para fins práticos.

3. **Magnitude clinicamente aceitável:** Apesar do desvio estrutural mencionado no item 1, a magnitude dos erros permanece clinicamente baixa. Com resíduos contidos em ±3 mmHg e um erro padrão residual (RSE) de 1.25 mmHg (< 2% da média de ~132 mmHg), o modelo possui alta precisão preditiva adequada para triagem clínica.

4. **Pontos de atenção:** Observam-se dois casos com resíduos mais elevados (> 2 e < -2 mmHg). Embora não invalidem o modelo, esses casos representam potenciais pontos de influência ou variações biológicas atípicas que merecem investigação adicional em estudos futuros.

**Conclusão:** O modelo de inclinações paralelas é **funcionalmente adequado e robusto** para uso em triagem clínica, embora a relação exata entre idade e pressão arterial possa apresentar uma complexidade adicional (aceleração não-linear com a idade) que uma função linear simples não descreve integralmente. Para aplicações de alta precisão, modelos não-lineares (ex: splines ou polinômios) poderiam capturar melhor essa curvatura.
:::

# Conclusões {#sec-conclusions}

## Principais Achados

1. **Idade como preditor dominante:** A cada ano de vida, a PAS aumenta aproximadamente **0.83 mmHg**, refletindo o processo natural de envelhecimento vascular e aumento da rigidez arterial.

2. **Efeito do gênero como deslocador:** Homens apresentam pressão arterial cerca de **10 mmHg superior** às mulheres na mesma faixa etária, mesmo com taxas de envelhecimento similares (inclinações paralelas). Isso pode estar relacionado a diferenças hormonais, composição corporal e fatores fisiológicos.

3. **Excelente acurácia preditiva:** O modelo combinado (idade + gênero) apresenta erro médio de apenas **±1.25 mmHg**, adequado para aplicações de triagem clínica em larga escala.

4. **Melhoria substancial:** Incluir gênero no modelo reduz o erro em **74.5%** comparado ao uso isolado de idade, demonstrando a importância de considerar características demográficas na predição.

## Aplicações Práticas

O modelo desenvolvido pode ser utilizado para:

- **Identificação precoce:** Detectar pacientes em risco de desenvolver hipertensão antes que sintomas apareçam
- **Estratificação de risco:** Priorizar grupos que necessitam rastreamento mais frequente
- **Educação de pacientes:** Demonstrar trajetórias esperadas de PAS ao longo da vida
- **Alocação de recursos:** Auxiliar na distribuição eficiente de recursos de saúde pública

## Limitações Críticas

**1. Dados Simulados:** Este projeto utiliza **dados fictícios** criados para fins exclusivamente educacionais. As relações lineares perfeitas observadas não refletem a complexidade biológica presente em dados reais.

**2. Tamanho Amostral Reduzido:** Apenas 30 pacientes fictícios foram incluídos, quantidade insuficiente para generalização populacional.

**3. Variáveis Omitidas:** Fatores críticos foram excluídos:

- Índice de Massa Corporal (IMC)
- Histórico familiar de hipertensão
- Uso de medicamentos anti-hipertensivos
- Comorbidades (diabetes, doença renal, etc.)
- Hábitos de vida (dieta, exercício, tabagismo)
- Fatores socioeconômicos
- Etnia e ancestralidade

**4. Linearidade Simplificada:** A relação real entre idade e PAS pode ser não-linear, especialmente em idades avançadas.

**5. Ausência de Validação Externa:** O modelo não foi testado em amostra independente.
:::

## Abordagens Alternativas

Este projeto utilizou **regressão de inclinações paralelas**, mas existem outras técnicas válidas:

- **Regressão com interação:** Permitir que a taxa de envelhecimento (slope) difira entre gêneros
- **Modelos não-lineares:** Usar polinômios, splines ou GAM para capturar acelerações
- **Regressão quantílica:** Modelar diferentes percentis (não apenas a média)
- **Modelos mistos hierárquicos:** Incorporar estruturas de agrupamento
- **Machine Learning:** Gradient Boosting, Random Forests para relações complexas

**A escolha depende de:** Questão clínica específica, dados disponíveis, tamanho amostral, requisitos de interpretabilidade.

# Pacotes necessários
library(tidyverse)
library(broom)
library(moderndive)

# 1. Criar dados
set.seed(42)
blood_pressure <- tibble(
  age = c(25, 30, 35, 40, 45, 50, 55, 60, 65, 70,
          28, 33, 38, 43, 48, 53, 58, 63, 68, 73,
          26, 31, 36, 41, 46, 51, 56, 61, 66, 71),
  gender = rep(c('Male', 'Female', 'Male'), each = 10),
  systolic_bp = c(118, 120, 125, 128, 132, 135, 140, 145, 150, 155,
                  110, 115, 118, 122, 125, 130, 135, 138, 142, 148,
                  120, 122, 127, 130, 135, 138, 142, 148, 152, 158)
)

# 2. Modelos
mdl_age <- lm(systolic_bp ~ age, data = blood_pressure)
mdl_gender <- lm(systolic_bp ~ gender + 0, data = blood_pressure)
mdl_both <- lm(systolic_bp ~ age + gender + 0, data = blood_pressure)

# 3. Comparação
metricas <- bind_rows(
  glance(mdl_age) %>% mutate(model = "Idade"),
  glance(mdl_gender) %>% mutate(model = "Gênero"),
  glance(mdl_both) %>% mutate(model = "Ambos")
) %>%
  select(model, r.squared, adj.r.squared, sigma)

# 4. Visualização final
ggplot(blood_pressure, aes(x = age, y = systolic_bp, color = gender)) +
  geom_point(size = 3, alpha = 0.6) +
  geom_parallel_slopes(se = FALSE, linewidth = 1.2) +
  geom_hline(yintercept = 140, linetype = "dashed", color = "red") +
