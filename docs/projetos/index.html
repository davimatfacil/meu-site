Regressão de Inclinações Paralelas

Predição de Pressão Arterial por Idade e Gênero

Análise estatística completa aplicando parallel slopes regression para modelar a relação entre idade, gênero e pressão arterial. Inclui análise exploratória, comparação de modelos, validação e interpretações clínicas.

Técnicas aplicadas: - Regressão linear múltipla - Parallel slopes regression - Análise de resíduos - Validação estatística - Visualizações com ggplot2

Tecnologias: R, tidyverse, broom, moderndive
